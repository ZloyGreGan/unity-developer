# 🔥 Шахматная школа Феномен

## 📌 Краткое описание
**Шахматная школа Феномен** — Мобильная шахматная игра для детского обучения

---

Участвовал в разработке проекта: обучающей мобильной шахматной игры для детей. Работал над реализацией UI, интеграцией экранов с бизнес-логикой и оптимизацией интерфейса под мобильные устройства.

---

## 👩‍💻 Мой вклад
- Разрабатывал UI-экраны на Unity UGUI по макетам из Figma с учётом адаптивности и требований мобильных устройств
- Реализовал ключевые пользовательские разделы: родительский экран, экран учителя, профиль пользователя, настройки профиля, дашборд со статистикой и экран выбора одежды
- Разработал систему премиум-доступа, включая UI-сценарии, состояние подписки и интеграцию с бизнес-логикой приложения
- Интегрировал UI с бизнес-логикой приложения в рамках MVVM-архитектуры
- Оптимизировал UI под мобильные устройства: снижал лишние аллокации, контролировал Canvas rebuild, работу реактивных подписок и использование ресурсов на ключевых экранах
- Исправлял баги в UI, игровых сценариях, интеграции экранов и пользовательских флоу
  
---

## 🛠 Технологии
- Unity (C#, UGUI)
- DI: Zenject
- Асинхронность: UniTask, UnityWebRequest
- Архитектура: MVVM
- Реактивность: UniRx (Reactive Extensions)
- VCS: Git
